# Tvarita Mathur Portfolio Website

This is a one-page personal portfolio website for Tvarita Mathur, a rising senior, showcasing:

- Lab research
- Biomedical interests
- Legislative and GT Colorado State Student Board advocacy
- STEM leadership
- Contact links

## How to use

1. Open `index.html` in a browser to preview the website.
2. Edit the email in the Contact section.
3. Replace the LinkedIn and Resume `href="#"` links with real URLs.
4. Upload the folder to GitHub Pages, Netlify, Vercel, or another static hosting platform.

## Files

- `index.html` — website structure and content
- `styles.css` — design, layout, and responsive styling
